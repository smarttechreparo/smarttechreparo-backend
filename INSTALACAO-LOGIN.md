# Instalação do login

1. Execute `SQL-AUTENTICACAO.sql` no SQL Editor do Supabase e troque a senha temporária antes de executar.
2. No Railway, adicione `JWT_SECRET` com uma chave longa e aleatória e `NODE_ENV=production`.
3. Instale as dependências com `npm install`.
4. Publique o backend antes do frontend.

Login inicial definido no SQL:
- E-mail: admin@smarttechreparo.com.br
- Senha: o valor colocado no SQL antes de executá-lo.
